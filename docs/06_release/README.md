# Release dokumentumok

## Státusz

**Release-placeholder – a technikai scaffold futtatható alap, a teljes Core MVP még nem kiadható.**

Ez a mappa a későbbi demóhoz, release-hez és önértékeléshez kapcsolódó dokumentumok helye. A dokumentumok addig nem készülnek el release-állítással, amíg nincs tényleges, verifikált runtime és végigjátszható Core MVP.

Későbbi fájlok:

- `demo_script.md`
- `release_notes.md`
- `self_assessment.md`

A tervezett UX- és acceptance forgatókönyvek jelenleg a product, design és quality dokumentációban találhatók; ezek nem helyettesítik a későbbi, valós környezeten ellenőrzött demo scriptet vagy release note-ot.
